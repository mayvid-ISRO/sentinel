# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅                 |
| Older   | ❌                 |

## Reporting a Vulnerability

We take security seriously. If you find a vulnerability, please **do not open a public issue**.

Instead, report it directly:

- Open a [private security advisory](https://github.com/mayvid-ISRO/sentinel/security/advisories/new) on GitHub, or
- Email the maintainers through the repository's security tab

You will receive a response within **48 hours**.

## What to Include

When reporting a vulnerability, please include:

1. A description of the issue
2. Steps to reproduce
3. Potential impact
4. Your suggested fix (if any)

## Confidentiality

All reports are treated as confidential. We will not share details with third parties without your permission.
